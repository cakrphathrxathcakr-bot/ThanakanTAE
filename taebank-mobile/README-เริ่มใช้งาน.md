# TaeBank Mobile — ใช้ฐานข้อมูลเดิม

ชุดนี้ตั้งค่าให้เชื่อม Firebase **taebankwat** จากโค้ดเดิมแล้ว อ่านที่ /members และ /transactions เดิมโดยตรง ไม่ต้องอัปโหลดรายชื่อ ไม่ต้องนำเข้า CSV และไม่ต้องย้ายข้อมูลไป /bank

## เปิดใช้งาน

1. เปิด TaeBank-Mobile.html ใน Chrome, Edge หรือ Safari โดยเชื่อมอินเทอร์เน็ต
2. สมาชิกเลือก **สมาชิก** แล้วใช้เลขบัญชี/รหัสเดิม 6 หลัก
3. ผู้ดูแลเลือก **ผู้ดูแล** แล้วใช้รหัสผู้ดูแลและ Master Key เดิม

ชื่อ ยอดเงิน และประวัติจะอ่านจากฐานข้อมูลเดิมแบบสด การเปิดหน้าเว็บไม่สร้างข้อมูล ไม่รีเซ็ต และไม่เขียนทับข้อมูลเดิม

หากเปิดไฟล์โดยตรงแล้วเบราว์เซอร์จำกัดการเชื่อมต่อ ให้เปิดผ่านเว็บเซิร์ฟเวอร์หรือ Hosting เดิม โดยเก็บ index.html และไฟล์ประกอบไว้ในโฟลเดอร์เดียวกัน ไฟล์ HTML เดียวมีทุกส่วนรวมไว้แล้ว

## ความเข้ากันได้

- คง ID สมาชิกและ ID รายการเดิม รวมถึงชื่อและฟิลด์เพิ่มเติมที่มีอยู่
- อ่าน amount และ date แบบเดิม การแปลงเพื่อแสดงยอดทำในหน่วยความจำ ไม่เขียนค่าจำนวนเงินเดิมกลับฐานข้อมูล
- รักษายอดรวมเดิมแม้ดอกเบี้ยเก่ามีเศษต่ำกว่า 1 สตางค์
- อ่านสถานะ printed และตำแหน่งหน้าสมุดเดิม
- เมื่อผู้ดูแลยืนยันรายการใหม่ จึงบันทึกไปยังตำแหน่งเดิม พร้อมข้อมูลตรวจสอบใน /taebankMeta
- การบันทึกตรวจข้อมูลล่าสุดทั้งชุดด้วย transaction หาก Rules เดิมไม่อนุญาต ระบบจะแจ้งข้อผิดพลาดและไม่บันทึกแบบข้ามการตรวจ
- ปุ่มล้างข้อมูลทดลองไม่ปรากฏเมื่อใช้ฐานข้อมูลจริง

การเข้าสู่ระบบนี้รองรับวิธีเดิม รหัสตรวจในหน้าเว็บตามระบบเดิม สิทธิ์อ่าน/เขียนจริงยังขึ้นกับ Firebase Rules เดิม ชุดนี้ไม่ได้แก้ Rules หรือสิทธิ์ฐานข้อมูลให้คุณ

## โค้ดแยกไฟล์

index.html, styles.css, app.js, core.js, firebase-config.js, legacy-service.js และ service.js เป็นไฟล์หลัก

legacy-service.js เชื่อมฐานข้อมูลและรูปแบบเดิม ส่วน service.js ยังรองรับโหมดตัวอย่างและระบบ Firebase Authentication แบบใหม่เป็นทางเลือก

โฟลเดอร์ firebase/ และ SETUP-FIREBASE.md เป็นทางเลือกสำหรับระบบ Authentication แบบใหม่ ไม่ต้อง deploy ไม่ต้องย้ายข้อมูล และไม่ต้องทำตามคู่มือนั้นเพื่อใช้โหมดเดิมที่ตั้งค่าไว้

## ขอบเขตการตรวจ

ตรวจการอ่านฐานข้อมูลจริงแบบอ่านอย่างเดียว และทดสอบการแปลงข้อมูล/การบันทึกกับข้อมูลจำลอง ไม่ได้ฝาก ถอน จ่ายดอกเบี้ย หรือลบข้อมูลจริงระหว่างทดสอบ
